# صيدليتي — مشروع تحويل HTML إلى تطبيق Android

هذا المشروع يغلّف ملف `saydalati.html` داخل تطبيق Android يستخدم WebView، مع دعم JavaScript وDOM Storage وIndexedDB عبر عنوان محلي آمن من WebViewAssetLoader.

## أسهل طريقة لإنتاج APK من الهاتف

1. نزّل ملف ZIP لهذا المشروع وفك ضغطه إذا احتجت.
2. افتح https://github.com/new وأنشئ مستودعاً جديداً باسم `saydalati-android` واجعله فارغاً.
3. افتح المستودع، ثم اختر **Add file → Upload files** وارفع محتويات هذا المجلد (لا ترفع ملف ZIP وحده؛ ارفع الملفات والمجلدات بعد فك الضغط).
4. اضغط **Commit changes**.
5. افتح تبويب **Actions** داخل المستودع، ثم اختر **Build Saydalati APK** واضغط **Run workflow** إذا لم يبدأ البناء تلقائياً.
6. افتح عملية البناء الناجحة، وانزل إلى **Artifacts**، ثم نزّل `saydalati-debug-apk.zip`.
7. فك ضغط ملف الـArtifact، وثبّت `app-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

## معلومات
- هذا ملف APK تجريبي موقّع بمفتاح debug، مناسب للتجربة والتثبيت الشخصي، وليس إصدار متجر Google Play.
- لا يحتوي المشروع على إعدادات اشتراكات أو دفع إلكتروني؛ هو تحويل لواجهة HTML الحالية فقط.
- لا تضع مفاتيح توقيع أو كلمات مرور في المستودع.
